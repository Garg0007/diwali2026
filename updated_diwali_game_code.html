🌟 Game Design by Rishi Sir 🌟
🏠 Tab 1 (घर सजाओ): दीयों में पहले 1. बाती ➔ 2. तेल ➔ 3. माचिस लगाएं, फिर रंगोली सजाएं!
🕯️ पटाखे कैसे जलाएं (Tab 2, 3, 4):
1️⃣ बाईं तरफ रखे फुलझड़ी स्टैंड से फुलझड़ी उठाएं।
2️⃣ पास रखी जलती मोमबत्ती (Candle) से फुलझड़ी जलाएं।
3️⃣ अब 3 साइज़ के अनार, चकरी, सुतली बम, लक्ष्मी बम या रॉकेट जलाएं!
